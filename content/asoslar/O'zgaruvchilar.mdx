# O'zgaruvchilar

Go'da o'zgaruvchilar oshkora e'lon qilinadi. Kompilyator ularning turini o'zi kuzatib boradi va, masalan, funksiya chaqirilganda mosligini tekshiradi.

## E'lon qilish usullari

**var** kalit so'zi bilan oddiy e'lon:

```go
var a = "boshlang'ich"
```

Bir nechta o'zgaruvchini birdaniga e'lon qilish:

```go
var b, c int = 1, 2
```

**Type inference** — turini Go o'zi topib oladi:

```go
var d = true  // Go buni boolean deb tushunadi
```

**:= operatori** — qisqaroq yo'l (faqat funksiya ichida ishlaydi):

```go
f := "apple"  // var f string = "apple" o'rniga
```

## Boshlang'ich qiymatlar

Boshlang'ich qiymat bermasangiz, o'zgaruvchi standart qiymatni oladi:
- `int` uchun `0`
- `string` uchun `""`
- `boolean` uchun `false`
- qolgan turlarning ham o'z standart qiymati bor

```go filename="variables.go"
package main

import "fmt"

func main() {
    var a = "boshlang'ich"
    fmt.Println(a)

    var b, c int = 1, 2
    fmt.Println(b, c)

    var d = true
    fmt.Println(d)

    var e int
    fmt.Println(e)

    f := "apple"
    fmt.Println(f)
}
```

Natija:

```bash
$ go run variables.go
boshlang'ich
1 2
true
0
apple
```
