# For Loop

Go'da bitta yagona loop bor — `for`. Boshqa tillardagi `while` va `do-while` ni ham Go'da shu bitta `for` bilan yozamiz.

## 1. Shartli loop (while kabi)

```go
i := 1
for i <= 3 {
    fmt.Println(i)
    i = i + 1
}
```

Shart `true` bo'lib turgan ekan, loop davom etaveradi — xuddi `while` singari.

## 2. Standart for loop

```go
for j := 0; j < 3; j++ {
    fmt.Println(j)
}
```

Uch qismdan iborat: boshlang'ich qiymat; shart; har iteratsiya oxirida bajariladigan qadam.

## 3. Range bilan

```go
for i := range 3 {
    fmt.Println("range", i)
}
```

`0` dan `3` gacha aylanadi — `3` ning o'zi kirmaydi, ya'ni jami uch marta.

## 4. Cheksiz loop

```go
for {
    fmt.Println("loop")
    break  // break to'xtatish uchun
}
```

Shartsiz `for` — to'xtovsiz aylanaveradi. Uni `break` yoki `return` bilan to'xtatamiz.

## 5. Continue

```go
for n := range 6 {
    if n%2 == 0 {
        continue  // juft sonlarni o'tkazib yuborish
    }
    fmt.Println(n)
}
```

`continue` joriy iteratsiyani tashlab, to'g'ri keyingisiga o'tadi.

## To'liq misol

```go filename="for.go"
package main

import "fmt"

func main() {
    i := 1
    for i <= 3 {
        fmt.Println(i)
        i = i + 1
    }

    for j := 0; j < 3; j++ {
        fmt.Println(j)
    }

    for i := range 3 {
        fmt.Println("range", i)
    }

    for {
        fmt.Println("loop")
        break
    }

    for n := range 6 {
        if n%2 == 0 {
            continue
        }
        fmt.Println(n)
    }
}
```
