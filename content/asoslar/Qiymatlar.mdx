# Ma'lumot turlari va qiymatlar

Go'da bir nechta ma'lumot turi bor: string, butun son, float, boolean va boshqalar.

**String** — matnli ma'lumot. Stringlarni `+` bilan bir-biriga ulash mumkin. String doimo `""` yoki `` ` ` `` ichida yoziladi.

**Butun sonlar** — oddiy raqamlar: 1, 2, 100, -5.

**Float** — kasrli sonlar: 3.14, 7.0, -2.5.

**Boolean** — mantiqiy qiymatlar: `true` yoki `false`. Ular ustida `&&` (va), `||` (yoki), `!` (inkor) operatorlarini qo'llash mumkin.

```go filename="values.go"
package main

import "fmt"

func main() {
    fmt.Println("go" + "lang")

    fmt.Println("1+1 =", 1+1)
    fmt.Println("7.0/3.0 =", 7.0/3.0)

    fmt.Println(true && false)
    fmt.Println(true || false)
    fmt.Println(!true)
}
```

Natija:

```bash
$ go run values.go
```
