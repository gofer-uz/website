# Hello World Loyihasi

Keling, birinchi dasturimizni yozamiz — oddiygina Hello World.

```go filename="hello-world.go"
package main

import "fmt"

func main() {
    fmt.Println("hello world")
}
```

Bu kodni `.go` kengaytmasi bilan saqlang, masalan `hello-world.go` yoki `main.go`.

Ishga tushiramiz:

```bash
$ go run hello-world.go
hello world
```

## Kompilyatsiya qilish

Ba'zan dasturni alohida ishga tushiriladigan fayl qilib saqlash kerak bo'ladi. Buning uchun `go build` ishlatamiz:

```bash
$ go build hello-world.go
$ ls
hello-world    hello-world.go
```

Endi hosil bo'lgan faylni to'g'ridan-to'g'ri ishga tushirsak bo'ladi:

```bash
$ ./hello-world
hello world
```

Mana, Go dasturlarini ishga tushirish va kompilyatsiya qilishni ko'rib chiqdik. Keyingi qismda Go'ning ma'lumot turlari bilan tanishamiz.
